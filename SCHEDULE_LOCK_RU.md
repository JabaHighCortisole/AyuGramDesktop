# Расписание доступа AyuGram

## Правило

Часовой пояс фиксирован: `Europe/Moscow`.

- Понедельник–суббота: доступ с 15:50 включительно до 02:00 следующего дня.
- Воскресенье 00:00–01:59 — продолжение субботнего окна.
- Воскресенье с 02:00 и до понедельника 15:50 — блокировка.
- Проверка выполняется при открытии/возврате приложения и периодически во время работы.

## Проверочные границы

| Момент (МСК) | Ожидаемое состояние |
|---|---|
| Пн 15:49 | закрыто |
| Пн 15:50 | открыто |
| Вт 01:59 | открыто |
| Вт 02:00 | закрыто |
| Сб 23:59 | открыто |
| Вс 01:59 | открыто |
| Вс 02:00 | закрыто |
| Вс 15:50 | закрыто |
| Пн 01:59 | закрыто |

## Границы защиты

Это блокировка интерфейса внутри модифицированного AyuGram. Она не запрещает запуск официального Telegram, Telegram Web или другого клиента; не блокирует сетевые запросы фонового процесса и не защищает от удаления приложения, очистки данных, завершения процесса или действий администратора ОС. На Android без root/Device Owner это не может быть системным ограничением. На Windows пользователь с правами администратора также может обойти или удалить локальную блокировку.

## Состояние реализации

Код добавлен в feature-ветку как начальная интеграция. Сборка APK/EXE и проверка на реальных устройствах ещё не выполнены. Перед выпуском нужно прогнать тесты границ расписания, собрать оба проекта и проверить сценарии сна/возврата, смены даты, смены системного часового пояса и изменения времени.
